Generate an incident brief as valid JSON with:

- location_summary: extracted or inferred location (or null if unclear)
- key_facts: list of 3-5 bullet-point facts from the complaint
- recommended_action: specific recommended next step for the reviewer
- evidence_required: true if the complaint would benefit from citizen-provided photos or documentation

Rules:
- Write in professional but accessible language.
- Do NOT reproduce PII placeholders as if they are real data.
- Clearly note this is an AI-generated draft — the reviewer must verify all facts.
- Return only the JSON object. No markdown.
